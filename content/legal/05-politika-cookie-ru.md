## 2. ЧТО ТАКОЕ COOKIE-ФАЙЛЫ

2.1. **Cookie-файл** — небольшой текстовый фрагмент данных, который веб-сервер направляет браузеру Пользователя и который сохраняется на его устройстве. При последующих обращениях к Сайту браузер передаёт этот фрагмент обратно серверу.

2.2. Cookie-файлы позволяют Сайту «запоминать» действия и предпочтения Пользователя (авторизацию, содержимое корзины, язык интерфейса, настройки согласия) в течение сессии или между посещениями.

2.3. Наряду с cookie-файлами на Сайте могут применяться **аналогичные технологии**:

- **localStorage и sessionStorage** — локальные хранилища браузера;
- **пиксели (веб-маяки)** — прозрачные изображения размером 1×1 пиксель, используемые для регистрации факта загрузки страницы или письма;
- **SDK и скрипты** сторонних сервисов аналитики и рекламы.

Для целей настоящей Политики все указанные технологии именуются «cookie-файлы».

2.4. **Классификация по сроку хранения:**

- **Сессионные** — удаляются автоматически при закрытии браузера;
- **Постоянные** — сохраняются на устройстве в течение установленного срока либо до удаления Пользователем.

2.5. **Классификация по источнику:**

- **Собственные (first-party)** — устанавливаются доменом sharmaster.kz;
- **Сторонние (third-party)** — устанавливаются доменами третьих лиц (сервисы аналитики, рекламные платформы, платёжные провайдеры).

| Mozilla Firefox | Настройки → Приватность и защита → Куки и данные сайтов |
| Safari | Настройки → Конфиденциальность |
| Microsoft Edge | Настройки → Файлы cookie и разрешения сайтов |
| Opera | Настройки → Конфиденциальность и безопасность |
| Yandex Browser | Настройки → Сайты → Расширенные настройки сайтов |

6.2.2. Пользователь также вправе использовать режим приватного просмотра, при котором cookie-файлы удаляются после закрытия окна браузера.
